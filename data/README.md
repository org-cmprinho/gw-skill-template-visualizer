# High-Damage PvE Builds by Profession

Picks from the GW Teams & Builds Discord export, all PvE.
For each profession: one **player build** (paste the code into the skill window) and a **hero team** to run with it.
Folder paths point into `GW-Teams-and-Builds/Skills/` in the zip.

## Installation

1. Unzip `GW-Teams-and-Builds.zip`.
2. Copy the channel folders **inside** `GW-Teams-and-Builds/Skills/` (not the `Skills` folder itself) into the game's template folder:

   | Setup | Template folder |
   |---|---|
   | Windows (standalone or Steam) | `C:\Users\<you>\Documents\Guild Wars\Templates\Skills\` |
   | Documents moved to OneDrive | `C:\Users\<you>\OneDrive\Documents\Guild Wars\Templates\Skills\` |
   | Wine / CrossOver / Steam Proton | `<prefix>/drive_c/users/<you>/Documents/Guild Wars/Templates/Skills/` |

   If `Templates\Skills` doesn't exist, save any build once in game (Skills window → **Save**) and it will be created. You can also create the folders yourself.
3. In game: open the Skills & Attributes window (**K**) → **Load**. The channel folders show up there, and each build folder holds one template per party slot.
4. For heroes: open the hero's panel, go to its Skills tab → **Load**, and pick that slot's file.

Files are named `<slot> [a/b/c alternative] <Primary-Secondary> [note].txt`. `BUILD_INDEX.md` and this README can stay outside the game folder.

## Notes

- **Strongest overall for damage:** a TaO Ranger with **TaO Dominance**. A physical core of Rangers plus a Heroic Refrain Paragon (Rampage Pack, Paragonway) comes a close second.
- Hero gear matters a lot: see `BUILD_INDEX.md` and the server's `equipment-heroes` channel (runes, +5 Spawning Power, 20/20 sets).
- Turn off Mark of Pain when you're body-blocking, because it scatters mobs. Use Rigor Mortis only if enemies block.
- The Dervish channel has no posted builds. The Dervish pick comes from team posts that name an Avatar of Balthazar (AoB) Dervish player.
